# UPI Suraksha Mitra - Frontend (React + Vite + Tailwind CSS)

Modern, accessible, multilingual citizen web platform for UPI fraud prevention and cybersecurity awareness.

## Technology Stack
- React 18
- Vite
- Tailwind CSS
- Lucide React Icons
- React Router DOM
- LocalStorage Internationalization (English, తెలుగు, हिन्दी)
- Dark & Light Mode Support

## Setup & Run Instructions

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
